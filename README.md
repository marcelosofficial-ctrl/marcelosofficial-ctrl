## Selected work

### CrashScope 1.2 · released
Local-first Windows crash diagnostics for games, hardware testing and GPU-heavy workloads. The public 1.2 release includes a native WPF/WebView2 desktop shell, ConfigTrace 1.0.1 integration, persistent incident evidence, Event Log + WER correlation, privacy-safe support bundles and **266/266 automated .NET tests**. It has been validated on the main AMD system and on a second Windows/Intel machine.

[Case study](https://marcelosofficial-ctrl.github.io/portfolio/projects/crashscope/)

### EasyFlix 1.4 · released
MIT-licensed WPF/.NET 10 local-media application with read-only multi-drive indexing, offline/removable-drive resilience, playback state, Favorites and deterministic media-intake automation. The verified public 1.4.0 release passed **219 automated tests with zero build warnings** and ships as installer + portable win-x64 artifacts with SHA-256 checksums.

[Source](https://github.com/marcelosofficial-ctrl/EasyFlix) · [v1.4.0 release](https://github.com/marcelosofficial-ctrl/EasyFlix/releases/tag/v1.4.0) · [Case study](https://marcelosofficial-ctrl.github.io/portfolio/projects/easyflix/)

### RevDev · active development
Native .NET 8/WPF control surface for durable multi-project AI-assisted development via Dev Relay, with guarded execution, persistent Git/result/goal continuity, grouped progress and liveness state, failure learning and a five-provider tool hub. It remains **active development**, not a public release.

[Case study](https://marcelosofficial-ctrl.github.io/portfolio/projects/revdev/)

### VektorDeck 1.0 · released
Local-first AI workstation manager for GGUF model intelligence, runtime safety, hardware telemetry, evidence-aware benchmarking and explainable launch recommendations.

[Case study](https://marcelosofficial-ctrl.github.io/portfolio/projects/vektordeck/)

### Retro Game Vision · field tested
Evidence-driven computer-vision and market-intelligence system for Japanese retro games with provenance, uncertainty, compatibility gates and reproducible resale-decision validation.

[Case study](https://marcelosofficial-ctrl.github.io/portfolio/projects/reseller-ai/)
